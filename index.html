Frequently asked questions

What is a RACI matrix?

A RACI matrix maps every task in a project to the people involved in it. R is Responsible (does the work), A is Accountable (owns the outcome — ideally exactly one per task), C is Consulted (gives input before the work happens), and I is Informed (told after). It removes the most common project failure mode: everyone assumes someone else is doing it.

How many people can be in a matrix?

There is no hard limit. As a practical guide, a RACI matrix stays readable up to about 8–10 team members per row. Beyond that, split the project into workstreams and maintain one matrix each.

Is there really no sign-up?

Correct. The generator runs entirely in your browser using JavaScript — your data does not leave your machine unless you explicitly press Save.

Can I use the result commercially?

Yes. There is no licence restriction and no watermark. Use it in client deliverables, internal documentation or proposals.

Why should there only be one Accountable person per task?

Because accountability is a single decision point. When several people are marked Accountable for the same task, nobody is — the task stalls or the blame diffuses. Our generator flags this automatically so you catch it early.
